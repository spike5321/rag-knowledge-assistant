# 知识库问答助手 · 产品设计文档

版本：v0.1（MVP）
日期：2026-09-05

## 1. 产品定位

把文档放进去，就能基于文档内容提问，并得到**带引用来源**的回答。

一个基于 RAG（检索增强生成）的个人知识库问答应用。目标是在最小范围内跑通完整链路：文档处理 → 向量检索 → 大模型生成 → 引用溯源，为后续的 Agent 化演进打基础。

## 2. 目标用户与场景

- 目标用户：有个人文档资料（笔记、论文、产品手册、规章制度等）希望快速检索问答的用户
- 典型场景：上传一批文档后，用自然语言提问，快速获得答案并知道答案出处

## 3. 主要功能（MVP 范围）

### F1 文档入库
- 支持 PDF / TXT / Markdown 三种格式，支持单个上传与本地文件夹批量导入
- 文档自动切分为片段（约 500 字符，相邻片段有重叠），调用智谱 embedding-3 向量化后存入 Chroma
- 重复上传同名文档时进行去重提示

### F2 检索问答
- 用户提问 → 向量检索 top-4 相关片段 → 拼装提示词 → glm-4-flash 生成回答
- 回答仅基于检索到的资料，资料不足时明确告知，不编造

### F3 引用溯源
- 每条回答下方展示引用片段：来源文件名、相似度分数、原文摘录
- 回答正文中以 [1] [2] 编号标注引用位置

### F4 多轮对话界面
- Streamlit 聊天式界面，保留会话历史
- 侧边栏提供文档上传与入库入口

## 5. 技术选型

| 项 | 选择 |
|---|---|
| LLM | 智谱 glm-4-flash（免费） |
| Embedding | 智谱 embedding-3 |
| 向量库 | Chroma（本地持久化） |
| 界面 | Streamlit |
| 语言/测试 | Python 3.11 / pytest |

## 6. 非功能要求

- 全程本地运行，API Key 通过 `.env` 注入，不硬编码
- 切分等核心逻辑具备单元测试；外部 API 调用可 mock

## 7. 验收标准

1. 上传 PDF 与 Markdown 各一份，成功入库并显示片段数
2. 针对文档内容提问，回答准确且带引用来源
3. 问文档中不存在的内容时，模型明确说明资料未提及
4. 切分逻辑单元测试通过
5. README 步骤清晰，可按文档一键跑起

## 8. 演进路线（Roadmap）

- v1.1：流式输出、检索参数调优、失败重试
- v1.2：混合检索 + Rerank，RAGAS 检索质量评测报告
- v2.0：工具调用（联网搜索等），升级为 Agent；引入 LangGraph 编排
